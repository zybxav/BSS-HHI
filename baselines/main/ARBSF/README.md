# ARBSF

Reference: Du et al., [Top-k Discovery Under Local Differential Privacy: An Adaptive Sampling Approach](https://doi.org/10.1109/TDSC.2024.3471923), IEEE TDSC, 2025.

On Windows with MATLAB and PowerShell, decompress the selected dataset from `data/main/` and set its text-file path and experiment parameters at the top of `work8_long_s/run_example.m`. Set MATLAB's current folder to `work8_long_s/` and run:

```matlab
run_example
```

Results are saved to `work8_long_s/experiment_runner/results/<dataset_name>.csv`.
